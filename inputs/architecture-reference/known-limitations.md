# Limites connues

- Aucun broker, outbox ou garantie de livraison n'est démontré.
- Les consommateurs d'une annulation sont supposés, pas validés.
- `EnrollmentCancelled.v1` est candidat non contractuel.
- Authentification, paiement et notification réels sont hors périmètre.
- Données exclusivement synthétiques; aucune donnée personnelle réelle.
- Event Sourcing n'est pas le mécanisme de persistance principal.
