# Preuves transférées

- tests domaine: bornes remboursement, transition et événement unique;
- tests application: horloge remplaçable et idempotence;
- test PostgreSQL: dernière place et annulation répétée;
- règles d'import: domaine/application indépendants des adapters;
- diagrammes: context map, composants et séquences.

Les résultats doivent être reproduits dans le dépôt source; ce handoff transmet les affirmations et décisions, pas une branche évaluée.
