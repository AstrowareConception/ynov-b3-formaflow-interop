# Diagrammes

Les huit sources Mermaid et leurs rendus SVG sont livrés dans `../docs/diagrams/` : contexte, producteurs et consommateurs, séquences synchrone et asynchrone, routage RabbitMQ, retry/DLQ, compatibilité V1/V2 et parcours des séances.

Un diagramme doit nommer producteurs, contrats, versions, transports et consommateurs. Il reste cohérent avec le code et accompagne une décision ; il ne remplace ni les tests ni les preuves d'exécution.
