# Commandes étudiantes

Créer un environnement Python 3.12 standard puis exécuter `python scripts/tasks.py setup`. Sous Windows, `./scripts/tasks.ps1 setup` sélectionne Python 3.12. Les mêmes tâches existent via `python scripts/tasks.py <tâche>` ; GNU Make est facultatif.

À `course-start`, utiliser `python scripts/validate_repo.py --stage course-start` puis `python -m pytest`. Les commandes des checkpoints suivants sont présentes mais deviennent fonctionnelles au fil du parcours.
