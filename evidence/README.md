# Preuves

Les preuves sont regroupées par scénario et permettent à un tiers de reproduire le constat : commande, version, entrée, sortie attendue, sortie observée et limite.

`async/` accueillera les traces nominales et les injections de panne. `versioning/` accueillera tests de compatibilité, exécution du client v1, migration et rollback. Les secrets et données personnelles réalistes sont interdits.
