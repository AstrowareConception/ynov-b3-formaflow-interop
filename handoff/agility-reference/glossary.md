# Glossaire

- Événement métier : fait interne au domaine source.
- Événement d'intégration : fait stable destiné à des consommateurs externes au domaine.
- Writer/reader : schéma utilisé à l'écriture et à la lecture.
- Downcast : adaptation explicite V2 vers V1.
- Idempotence : répétition sans second effet incontrôlé.
- DLQ : file isolant les messages après échecs bornés.
- Correlation ID : identifiant reliant les traces d'un parcours.
