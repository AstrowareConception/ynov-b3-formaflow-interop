# Incident de référence

Un JSON V2 a été envoyé directement à un client V1 strict. La file Administration augmente, Notification continue et aucun message n'est perdu. Il faut diagnostiquer le contournement probable du downcast, mitiger sans purge, définir le signal de reprise et prioriser la migration. Les options et leur priorité restent à travailler dans le module Agilité.
